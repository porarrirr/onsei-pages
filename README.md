# Onsei Pages

[Onsei](https://github.com/porarrirr)（オンデバイス日本語音声合成）の App Store 向け公開ページです。GitHub Pages で配信します。

| ファイル | 内容 |
|----------|------|
| `index.html` | ランディング |
| `support.html` | サポート |
| `privacy.html` | プライバシーポリシー |
| `terms.html` | 利用規約 |
| `styles.css` | 共通スタイル |

## ローカル確認

```sh
python3 -m http.server 8765
```

http://localhost:8765/ を開いて確認してください。
